# 多語系（I18N）

tokaPortal 2.3.0 起，所有玩家看得到的文字都放在共用套件 tokaI18n（`dev.toka:tokaI18n:0.1.0`，建置時內嵌並重新命名為 `dev.toka.pl.tokaPortal.internal.i18n`）的語系檔，程式裡不再有中文字串。目前只提供繁體中文 `zh-TW`；`en-US` 尚未製作。

- 語系檔：`src/main/resources/lang/zh-TW.yml`（UTF-8），共 **163 個 key**。
- 語言設定：`config.yml` 的 `language`（預設 `zh-TW`）。
- 覆蓋：伺服器擁有者可把同名檔放進 `plugins/tokaPortal/lang/`，只寫要改的 key。
- 程式取用：`Main.text("key", 參數…)`、`Main.lines("key")`、`Main.help(sender, "指令")`；`Main` 持有 `Messages`（`Main.messages()`）。
- 測試：`LanguageFileTest` 檢查檔內每個 key 都讀得到，且原始碼中的 `text("…")`／`lines("…")`／`help(sender, "…")` 字面值都存在於檔內，每個指令都有 `cmd.<指令>.desc`、`cmd.<指令>.usage`、`help.<指令>`。
- 注意：YAML 1.1 會把 `yes`、`no`、`on`、`off` 當成布林值，不可當 key 名稱（按鈕 key 因此用 `agree`／`refuse`）。

## 分區與 key 數

| 區 | key 數 | 內容 |
|---|---|---|
| `cmd.<指令>.desc/usage` | 22 | 11 個指令的說明與用法 |
| `param.*` | 6 | 客戶端指令提示的參數名稱（操作、住家名稱…） |
| `help.<指令>` | 11 | 每個指令的 help（多行清單） |
| `err.*` | 33 | 錯誤與拒絕 |
| `msg.*` | 19 | 玩家訊息 |
| `ui.*` | 55 | 表單標題、按鈕、內容、傳送標題字幕、血條冷卻字 |
| `log.*` | 13 | 後台文字 |
| `status.*` | 4 | 目前位置、預設傳送點名稱、傳送紀錄方向 |

## 每個指令的 help 位置

`/<指令> help` 都會輸出 `help.<指令>`（`/portal help` 原本就有，內容已補齊）。

| 指令 | key | 指令 | key |
|---|---|---|---|
| `/back` | `help.back` | `/tph` | `help.tph` |
| `/home` | `help.home` | `/tpl` | `help.tpl` |
| `/next` | `help.next` | `/tpp` | `help.tpp` |
| `/portal` | `help.portal` | `/tpw` | `help.tpw` |
| `/spawn` | `help.spawn` | `/wild` | `help.wild` |
| `/tpa` | `help.tpa` | | |

## 顏色套用對照

| 位置 | 套用 |
|---|---|
| 玩家訊息 | 前綴固定 `§7[傳送]§r`，一般文字 `§b`，名稱／數字 `§a`，成功 `§a`，錯誤／拒絕 `§c`，需注意 `§e`，用法 `§7`／`§e` |
| help | 標題 `§6§l`，每行 `§e/指令 <參數> §7- §b說明` |
| 後台 log | 不加方括號標籤；文字 `§b`、數字與名稱 `§a`、警告 `§e`、錯誤 `§c` |
| 表單標題、按鈕 | 維持原本的樣式（按鈕前綴 `§e>>§8` 等），沒有套用慣例色 |
| 傳送標題字幕 | 錯誤標題 `§c`、`§e無法傳送`、`§b正在傳送...` |

## 不翻譯／不抽出的項目

- 指令名、權限節點（`tokaPortal.points.manage`）、config key、事件名稱、世界與傳送點類型 code（`point`、`shopbox`、`home`）、zero 功能代碼（`PLAYERS`、`REGIONS`、`LAND`、`CITY_PASS`）。
- 給開發者看的例外訊息（`BaseDataProvider`、`HomeStorage`、`StorageManager`、`PublicPoints`、`teleportPoint`）改為英文，不進語系檔。
- 啟動失敗的 `IllegalStateException` 訊息（儲存無法開啟）使用 `err.storageOpen`。

## 待確認

1. **plugin.yml 的 `description`（`[prjToka]傳送插件`）與權限說明（`管理公共傳送點`）** 是靜態中文，核心不支援語系；維持原樣。
2. **「請在遊戲內使用」文字統一**：原本有「請在遊戲內進行」、「僅供遊戲內使用」、「僅可在遊戲內使用」三種，且有的沒有 `[傳送]` 前綴、有的是 `§e`；統一為 `err.playerOnly`（`§c`，含前綴）。
3. **`help` 子指令與名稱衝突**：`/tpa help`、`/tph help`、`/tpl help`、`/tpp help`、`/tpw help`、`/home help` 現在會顯示說明；若有玩家、住家、領地、傳送點、世界剛好叫 `help`，無法再用該指令直接傳送（住家與傳送點仍可從表單／選單選取）。
4. **表單與按鈕文字同時用來判斷點了哪個表單／按鈕**（沿用原本做法）：語系檔內表單標題與按鈕文字在同一語言內不可重複，也不建議讓使用者覆蓋成相同文字。
5. **按鈕與表單標題的顏色**（例如 `§e>>§8傳送點列表`）不在慣例表內，保留原樣。
6. **血條冷卻文字** `ui.wild.cooldownBar`（`[隨機傳送]冷卻剩餘 ${0} 秒`）送給 tokaDisplay 顯示，保留原本含方括號且無色碼，以免與 tokaDisplay 的樣式衝突。
7. **原本沒有 `[傳送]` 前綴或色碼的訊息**（如「住家名稱不得為空」）現在一律套用前綴與 `§c`／`§a`；`err.wild.noSafeSpot` 用 `§e`（暫時找不到落點，可重試）。
8. **`PlayerPortalEvent.toString()`** 原本回傳含 `[傳送]` 的中文文字，現在改走 `log.portalEvent`（沒有前綴與色碼）；若 zero 或其他插件依賴舊格式需再確認。
9. **StorageManager 的設定錯誤訊息**（舊 `storage.type`、backend 不支援、需離線搬遷）原本是中文，管理員在啟動失敗時會看到；因為是靜態工具且被單元測試直接呼叫，改為英文，之後若要中文化需改成傳入 Messages。
10. **`param.*`** 是客戶端指令清單顯示的參數名稱，不屬於 `ui` 區，慣例表沒有對應分區，暫用 `param`。
